# 공공데이터포털 자격 · 검정 데이터 조사 (2026-11-18)

공공데이터포털에서 키워드 7개(자격 · 검정 · 자격증 · 시험일정 · 국가시험 · 면허시험 · 자격시험)를 오픈API · 파일데이터 전체 페이지로 검색해 1,932건을 모았다. 그중 무관한 것(수급자격 · 입찰참가자격 · 입주자격 등)을 빼고 785건을 남겼고, 여기에는 플래너에 쓸 것만 적는다.

- 링크: `https://www.data.go.kr/data/{번호}/openapi.do` (오픈API) · `.../fileData.do` (파일데이터)
- **상태**: ✅ 연동 끝 · 🔑 활용신청 필요 · 📄 파일만 있음 (HWP · PDF 라 자동변환 API 없음 → 사람이 옮겨 적거나 RAG 문서로)

## 확인 결과: 공식 데이터가 없는 분야

금융(금융투자협회 · 한국금융연수원), 대한상공회의소(컴활 · 워드 · 유통관리사), 한국생산성본부(ITQ · GTQ), 어학(TOEIC 등)은 이번 검색에서 일정 데이터를 찾지 못했다. → 공고문 보충 데이터(`data/manual_schedules.json`)로 넣는다.

## 파일데이터 vs API — 어떻게 가져올까

| 출처 형태 | 쓰는 방법 | 이유 |
|---|---|---|
| 실시간 오픈API (A-1) | 그대로 호출 | 최신 값. 과제의 "외부 API" 요건에 정확히 맞는다 |
| 파일데이터 + 자동변환 API (A-2) | **자동변환 API 로 호출**, 실패하면 내려받은 CSV 로 대체 | 코드는 같은 어댑터(`table.py`)로 처리. 단 파일이 새로 올라오면 주소(uddi)가 바뀌므로 설정의 `endpoint` 를 갱신해야 한다 |
| HWP · PDF 만 (A-3) | 사람이 옮겨 적기(`manual_schedules.json`) 또는 RAG 문서 | 자동으로 읽을 수 없다 |
